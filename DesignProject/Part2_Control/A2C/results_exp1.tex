\subsection{Results}
\label{sec:exp1}

We trained PPO and A2C across all combinations of three design choices: the
reward function (the \emph{base} task reward vs.\ the \emph{tuned} shaped
reward), the observation encoding (raw $[\theta,\omega]$ vs.\ the
wrap-invariant $[\sin\theta,\cos\theta,\omega]$), and the disturbance setting
(nominal vs.\ \emph{robust} training with actuator noise and dropped commands).
Every run was capped at $10^6$ steps with early stopping; we report the wall
clock training time, the environment steps actually trained, and the mean
return over 10 evaluation episodes (Table~\ref{tab:exp1}).

\paragraph{PPO clearly outperforms A2C.}
PPO achieves a mean return of $161.1$ (median $175.7$) against A2C's $51.0$
(median $44.5$), while training roughly twice as fast on average ($4.5$ vs.\
$10.0$ min). A2C's best run ($97.6$) only matches PPO's \emph{worst}, and its
returns are far more variable (std.\ $41.0$ vs.\ $33.8$): several A2C
configurations effectively fail to learn the swing-up (return $<30$). On this
task A2C is therefore not competitive.

\paragraph{A reward ceiling near $181$.}
Multiple PPO configurations converge to almost exactly the same return
($\approx 181$), indicating a task-imposed reward cap rather than remaining
headroom. The best controller is consequently the cheapest one that reaches
this ceiling: \texttt{PPO, base reward, sincos} converges in $1.3$ min
($150$k steps). Importantly, the two \emph{robust} PPO runs also reach
$\approx 181$, so training under actuator noise and dropped commands costs
essentially no performance --- an encouraging result for sim-to-real transfer.

\paragraph{More compute did not help.}
Return correlates negatively with training time ($r=-0.86$); the longest runs
are precisely the failed A2C runs that trained for many minutes yet scored low.
Within PPO the correlation is also negative ($r=-0.73$). Performance is thus
determined by the algorithm and configuration rather than by the compute
budget, and early stopping correctly halted converged runs well before the
$10^6$-step cap. The tuned/shaped reward did not reliably outperform the base
reward---for A2C it was clearly worse---suggesting the shaping mainly
destabilised the weaker learner rather than guiding it. Because each
configuration was run with a single seed, these secondary effects (reward
shaping, observation encoding) remain confounded and would need a seeded
full-factorial sweep to quantify.
